масштаб и поза

Управление размером объектов в кадре

Модель не понимает «сделай на 30% больше» — это абстракция. Она понимает пространственные отношения между элементами кадра.

не работает«Сделай кресло больше», «увеличь на треть», «кресло должно быть крупным».
работаетОписывай соотношение через конкретную точку отсчёта: «человек сидит так, что слева и справа остаётся пространство в пол-человека», «расстояние между коленом и подлокотником — 10 сантиметров», «подлокотники кресла на уровне локтей».
принцип

Якорь — это человек, не кресло

Размер человека в кадре модель держит стабильно. Кресло — нет. Поэтому описывай расположение кресла относительно человека, а не наоборот. Если человек стабилен — кресло «подтянется» под его пропорции.

поза из фильма

Референс-скриншот как Image 3

Нужна конкретная поза (например как у Шэрон Стоун в «Основном инстинкте»)? Не описывай словами — текст двусмысленный. Сделай скриншот именно того кадра → загрузи как Image 3 в Weavy → укажи в промте: pose from image 3.

схема из линий

Stick figure тоже работает

Если нет готового референса — нарисуй от руки человечка из линий в нужной позе и загрузи как Image 3. Модель читает позиционирование тела из схемы. Не нужно рисовать красиво.

«Иногда некорректно звучит "сделай на 30% больше". Вы можете описать расстояние — между ногой и подлокотником 10 сантиметров — и он примерно это оставит.»
claude · project

Identity lock через Project Instructions

Файлы в Knowledge работают — но модель обращается к ним по запросу. Если вшить описание героя прямо в Instructions, он будет применяться ко всем промтам автоматически, без явного упоминания.

  1. В Project Files (Knowledge) — загружены: filmcheck, сценарий, character sheet. Это база.
  2. В Project Instructions — написать: «Все промты пишутся для Weavy. Главная героиня всегда абсолютно идентична прикреплённому character sheet — одежда, украшения, причёска не меняются ни при каких условиях.»
  3. Почему это сильнее, чем файл. Instructions — это постоянно активная инструкция. Файл — это данные, которые читаются по мере необходимости. Сочетание двух уровней даёт двойную привязку.
  4. Новый чат для видеопромтов. Промты для изображений и промты для видео — разные задачи, разный контекст. Открывай отдельный чат внутри проекта под каждый тип задачи.
проблема с украшениями

Кольцо и часы — упрощай, не борись

Nano Banana Pro плохо понимает «кольцо на безымянном пальце правой руки» — запутывается в лево/право. Решение: упростить — пусть все украшения на одной стороне, не прописывать пальцы детально. Время на доводку украшений не стоит потраченных кредитов.

раскадровка

Стори-борд: текст → кадры → проверка

Раскадровка — это не иллюстрации, это текстовая карта кадров. Она нужна чтобы видеть план монтажа до начала генерации.

  1. Скопируй сценарий целиком → вставь в ChatGPT (или Claude) → напиши: «Сделай стори-борд». Модель распишет каждый кадр: план (крупный / средний / общий), движение камеры, действие героя.
  2. Проверь логику через Gemini. Вставь раскадровку в Gemini → «Проверь, правильно ли выстроена последовательность кадров». Gemini смотрит на структуру в целом и указывает на несостыковки. AI всегда может ошибиться — проверка обязательна.
  3. Отредактируй текстом. Если кадр не нравится — напиши: «Измени кадр 1, сделай общий план вместо крупного». Не трать кредиты на генерацию пока раскадровка не устраивает в тексте.
  4. Минимум кадров на 30 секунд — 10–12. Меньше = грубые склейки без плавных переходов.
«Важно прежде чем снять — мы всегда представляем себе как это выглядит. Этот текст помогает увидеть кадр ещё до генерации.»

start frame

Начальное изображение клипа

Первый кадр видеоклипа. Видеомодель «вырастает» из него — добавляет движение, анимирует. 20 кадров в ролике = нужно 20 start frames.

end frame

Завершающее изображение клипа

Veo 3.1 поддерживает end frame — куда должен прийти клип. Ты задаёшь начало и конец, модель заполняет движение между ними. Загрузи оба как изображения и опиши в промте: «first image = start frame, second image = end frame».

правило очерёдности

Weavy → видеомодель, не наоборот

Weavy генерирует только изображения. Видео — в отдельном инструменте (Veo, Kling). Сначала делаешь все нужные старт-фреймы (и энд-фреймы) в Weavy, скачиваешь их → потом идёшь в видеомодель. Не пытаться делать видео без готовых старт-фреймов.

идея перехода

Камера отъезжает — логотипы появляются на стене

Кадр: камера начинает с крупного плана героини → отъезжает назад (start frame = крупный план, end frame = общий план) → во время движения на стене за ней появляются/мигают логотипы люксовых брендов, как на проекторе. Описать в промте Veo/Kling: «camera pulls back from close-up to wide shot; luxury brand logos projected on the wall behind appear and fade periodically».

claude · skills

Создание кастомного скилла прямо в Claude

Если нужного скилла нет в библиотеке — создай его сам через скилл-криэйтор. Занимает 2–3 минуты.

  1. Открой Claude → в чате вызови встроенный skill-creator через /.
  2. Опиши задачу. Пример команды: «Создай скилл для написания кинематографических промтов для видеомоделей Kling и Veo с использованием камеры ARRI, плавной лакшери студийной съёмкой».
  3. Claude генерирует .md файл — готовый скилл в формате, который принимает Claude.
  4. Скачай файл → иди в Customize → Skills → Create/Upload skill → загрузи .md.
  5. Готово. Скилл появляется в списке, вызывается через / в любом чате.
когда создавать кастомный скилл

Специфичная задача, которая будет повторяться

Если тебе нужно что-то узкое — например, промты именно под твой проект с конкретным стилем съёмки, конкретным героем — бери туториалы и гайды по теме, делаешь выжимку ключевых правил, даёшь в Claude: «по этим правилам создай скилл». Получаешь персональный инструмент.

«В нейросетях самое главное знать — не надо делать что-то, что ты не умеешь. Берёшь туториалы из которых понял принцип, делаешь выжимку — и отдаёшь в клод, чтобы он сделал из этого скилл.»
инструмент

Whisper Flow — установка и настройка

Диктовка вместо набора текста. Работает в браузере, автоопределяет язык, умный транскрайбер (исправляет оговорки сам).

  1. Установка. Сайт: набери в браузере wflow → найди сайт → кнопка Download → установить для своей системы.
  2. Настройки. После установки: Creator → разрешить доступ к микрофону (Allow) → Language: оставь Auto-detect → включи все тумблеры инструментов.
  3. Горячая клавиша. По умолчанию — пробел или Function. Если Function меняет раскладку клавиатуры → переназначь на Option / Alt (она ни к чему не привязана).
  4. Использование. Поставь курсор в поле ввода (промт, чат, документ) → зажми горячую клавишу → говори → отпусти → текст вставился.
  5. Важно. Если курсор не стоит в нужном поле — Whisper Flow всё равно запишет фразу и сохранит буфер. Можно вставить потом вручную.
умный транскрайбер

Исправляет оговорки сам

Whisper Flow понимает контекст фразы. Если оговорился или сказал лишнее — он корректирует. Пунктуацию тоже ставит автоматически. Язык переключать не нужно — говори хоть по-русски, хоть по-английски в одном потоке.

Continuum

Режим постоянной записи

Приложение должно быть всегда открыто (свёрнуто справа). В режиме Continuum — ждёт нажатия кнопки в любой момент, не нужно запускать заново каждый раз.

видеогенерация

Google Flow + Veo 3.1 — старт-фрейм в видео

Google Flow (vflow.google) — интерфейс для видеогенерации через Veo 3.1. Поддерживает start frame + end frame, что даёт точный контроль над движением камеры.

  1. Открыть Google Flow. Набери в браузере flow.google → войди через Google-аккаунт. Если нет проекта — нажми «Создать» / Continue.
  2. Интерфейс изменился (июль 2026). Теперь справа — описание задачи, внизу — агент-меню. Напиши что хочешь создать → выбери Video.
  3. Загрузить старт- и энд-фреймы. Нажми + → загрузи два изображения из Weavy. В промте укажи: «First image is start frame, second image is end frame».
  4. Написать видеопромт. Использовать синематический скилл в Claude → вставить результат в поле промта в Flow. Указать движение камеры, действие героини, атмосферу.
  5. Модель: Veo 3.1 (по умолчанию). Для липсинга + живая речь → Google Omni / Gemini 2.0 — лучший речевой диапазон сейчас.
  6. Генерировать. Flow работает через агента — первые кредиты бесплатные. Продолжать (Continue) если спросит.
Veo 3.1

Кинематографичность + start/end frame

Лучший вариант когда нужны точные движения камеры с контролем начального и конечного кадра. Русский язык понимает. Ограничения Google по авторским правам — не генерировать персонажей, похожих на известных людей.

Gemini Omni

Липсинг + живая речь

Когда нужно чтобы героиня произносила реплику с попаданием в губы — выбирать Omni. Хороший речевой диапазон, естественная артикуляция. Загружать фото персонажа + старт-фрейм + промт с текстом реплики.

сравнение

Kling vs Veo — что когда использовать

Veo 3.1 / Google Flow

Когда нужен контроль и качество

Start frame + end frame, кинематографичность, плавные движения камеры, русский язык. Ограничения по авторским правам — не будет генерировать сцены слишком жёсткие или персонажей похожих на реальных людей.

Kling 2.5

Когда нужна свобода контента

Китайская платформа, менее строгие ограничения. Работает с различными типажами и сценами. Выбор для контента где Veo ставит блок — творческий монтаж, смешение лиц и персонажей. Нужна подписка.

общий принцип

Начинать всегда с Veo

Качество и управляемость выше. Kling — запасной вариант для конкретных задач где Veo не справляется или блокирует контент. Не нужно сразу платить за обе подписки — сначала исчерпать возможности Veo.

ошибки

Частые ошибки этой сессии

ошибкаВ промте не прописан тип плана — модель сделала общий вместо крупного потому что промт содержал описание позы, но не крупность.
фиксВсегда явно прописывать тип плана в промте: close-up, medium shot, wide shot. Описание позы и описание крупности — это разные вещи, обе нужны.
ошибкаПромт слишком длинный — модель начинает игнорировать часть инструкций, результат непредсказуемый.
фиксРазбить на два промта: сначала проверить короткий базовый (герой + локация + поза), убедиться что работает, потом добавлять детали. Большой промт — не значит лучший результат.
ошибкаКресло рисуется маленьким потому что в промте написано только «большое кресло», без пространственной привязки.
фиксОписать через человека: «героиня сидит в кресле, локти на подлокотниках, между коленом и подлокотником 10 см, по бокам свободное пространство». Модель выстроит масштаб через эти соотношения.
ошибкаChatGPT пытается нарисовать картинку вместо написания промта — не понял задачу.
фиксВсегда начинать запрос словами «напиши промт» и добавить «не рисуй» — иначе после обновлений ChatGPT склонен генерировать изображение вместо текста.

🏠 Домашнее задание к сессии 04

  1. Завершить все старт-фреймы — пройти по всем 10 кадрам раскадровки, сгенерировать каждый в Weavy. Это база для следующей сессии.
  2. Для кадров с переходом — сгенерировать и энд-фрейм (широкий план с логотипами на стене за героиней).
