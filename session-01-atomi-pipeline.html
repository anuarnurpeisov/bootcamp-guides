Сессия 01: AI Production Pipeline для бренда

Как собрать полный конвейер от идеи до кадров для рекламного ролика — через Claude Project, ChatGPT, Gemini и Weavy с нодами Nano Banana Pro.

Claude Projects Weavy · Nano Banana Pro ChatGPT · Gemini Whisper Flow Brand: Atomi
стек

Инструменты и их роли

Каждый инструмент отвечает за свой уровень. Не пытаться делать всё в одном месте.

◆
Claude
Главный мозг проекта. Держит контекст бренда, пишет сценарии, рефайнит промты, работает внутри Project со всеми файлами.
✦
Gemini
«Возврат в реальность». Широкое поле — общая информация, проверка рыночной логики, исследование продукта по открытым источникам.
◈
ChatGPT
Исполнительный инструмент. Хорошо делает конкретные задачи при правильной настройке: промты для Weavy, стторибординг, первые кадры.
⬡
Weavy (imagine.art)
Нодовый редактор для генерации изображений. Nano Banana Pro — самая выгодная модель по соотношению цена/качество.
◎
Whisper Flow
Диктофон-транскрайбер прямо в браузере. Зажать кнопку → надиктовать → отпустить → текст в поле. Ускоряет ввод промтов.
«Gemini — это из общего в частное. Он даёт общий ответ, потом уходим в Claude в частное, и потом снова проверяем через общее.»
claude · project

Настройка Claude Project под бренд

Project = долгосрочный контейнер для всей работы с одним брендом. Все чаты внутри видят один контекст, не нужно каждый раз заново объяснять кто такой бренд.

  1. Создать проект. New Project → название = имя бренда (например Atomi) → краткое описание.
  2. Project Instructions. Это как Custom Instructions в ChatGPT — предустановка поведения для всего проекта. Попросить Gemini написать черновик инструкции: «Напиши инструкцию к проекту Claude, в котором будут генерироваться идеи для рекламных кампаний для соцсетей бренда Atomi». Получить → вставить в Instructions → заполнить пустые поля: целевая аудитория, форматы контента, тон голоса.
  3. Knowledge — файлы о бренде. Сюда грузить: досье компании (миссия, ценности, продукты), логотип, описания продуктов, портрет аудитории. Формат — .md, не PDF: занимает меньше токенов, быстрее обрабатывается.
  4. Как получить досье продукта. Запросить в Gemini информацию о продукте (например HimaChim) → сохранить как .md → загрузить в Knowledge проекта. Claude не нужно будет искать инфо в интернете — всё уже внутри.
  5. Запуск кампании. В любом чате внутри проекта написать: «Придумай рекламную кампанию для продукта [название], которая состоит из 3 Reels на одну неделю». Claude возьмёт все ценности бренда из Knowledge автоматически.
ключевой принцип

Чем больше контекста — тем точнее выход

AI даёт множество вариантов, максимально близких к запросу. Ваша работа — сортировка, а не слепое принятие. Хорошая идея — та, которую вы видите и решаете довести до зрелости, а не первая же выданная.

weavy

Создание персонажа в Weavy

В Weavy есть готовый конструктор героя — блоки с параметрами. Не рисовать с нуля, а менять значения в ячейках.

  1. Открыть готовую структуру. Использовать существующий шаблон с параметрами персонажа. Копируется для каждого нового героя — не делать с нуля каждый раз.
  2. Заполнить параметры. Возраст, тип телосложения, стиль одежды (home casual / casual), цвет волос, особые черты. Пример для HimaChim: мужчина, 30 лет, атлетическое тело, домашняя одежда, обычная короткая причёска.
  3. LLM-модуль Step 2. Нажать Run LLM Module — система собирает текстовое описание героя из всех параметров автоматически.
  4. Генерация в Nano Banana Pro. Формат 9:16, 2K — для соцсетей. Nano Banana Pro стоит 1 кредит (обычный — 3 кредита) и лучше держит элементы.
  5. Сохранить лучшую версию. Выбрать кандидата → сохранить. Он становится входным элементом Image 1 во всех последующих кадрах.
про Nano Banana Pro

1 кредит vs 3 кредита

Nano Banana Pro — 1 кредит за генерацию. Обычный Nano Banana — 3 кредита. Pro лучше понимает входные референсы и стабильнее держит идентичность. Всегда использовать Pro.

Пространственный контекст сцены

Добавить четвёртый нод — предыдущий сгенерированный кадр или схему расположения объектов. Описать его как «image 4 — расположение и масштаб предметов в сцене». Это даёт модели понимание где что стоит, убирает дрейф объектов между кадрами и передаёт цветокор/атмосферу.

правило промта

Всегда писать промт на английском

Nano Banana Pro работает на английском языке. Русский промт — хуже результат. ChatGPT или Claude используется для написания промта, который потом вставляется в Weavy.

промты

Генерация промтов через ChatGPT

ChatGPT настраивается специально как «писатель промтов для Weavy». Один запрос — промты для нескольких кадров сразу.

  1. Настроить ChatGPT. Загрузить раскадровку → указать, что чат пишет промты для Weavy с тремя нодами (image 1 = герой, image 2 = локация, image 3 = продукт).
  2. Запросить пачку промтов. Например: «Напиши промты для кадров 1, 2, 6. В Image 1 — персонаж, Image 2 — гостиная, Image 3 — продукт HimaChim на столе».
  3. Проверить выход. Хороший промт содержит прямые указания на ноды: use image 1 as character, use image 2 as living room environment. Без этого модель угадывает.
  4. Вставить в Weavy. Скопировать промт → вставить в текстовое поле ноды Nano Banana Pro → подключить изображения → Run Module.
  5. Негативный промт — для нежеланных элементов. Если появились книги, лишние предметы — попросить ChatGPT: «Добавь негативный промт: убери книги из кадра». Вставить отдельно.
«ChatGPT — очень исполнительный человек, которого нужно хорошо настраивать. Если что-то там неправильно, он будет выдавать поверхностные, очевидные вещи.»
консистентность

Как удерживать атмосферу кадр-в-кадр

Модель не помнит предыдущий кадр. Каждая генерация — новое событие. Нужно принудительно давать контекст.

метод 1

Предыдущий кадр как Image 4

Готовый кадр N → подключить как Image 4 следующей генерации с описанием: «image 4 — пространственное расположение, масштаб объектов, атмосфера». Камера не сдвигается, цвет и свет сохраняются.

метод 2

Orbit shot

Если кадр с одного угла повторяется — попросить ChatGPT: «Измени промт: другой ракурс, отличный от Image 4». Камера обходит героя по дуге (против часовой, в сторону окна) — появляется движение без разрыва сцены.

проблемаChatGPT нарисовал продукт из интернета, хотя вы его не загружали — нашёл упаковку HimaChim сам.
решениеЗагрузить фото продукта явно как Image 3. Когда визуал есть в ноде — модель берёт его, а не ищет в интернете. Если нет ноды — нет контроля.
видео

Start Frame — мост от изображения к видео

Weavy генерирует только изображения. Видео делается отдельно — в Seedance, Kling. Связующий элемент — start frame.

принцип

Схема: фото → старт-фрейм → видеоклип

Каждый кадр из Weavy — это начальный кадр (start frame) видеоклипа. 20 кадров в ролике = 20 start frames. Каждый клип ~3 секунды. Они склеиваются в монтаже. Weavy генерирует старт-фреймы, видеонейросеть продолжает движение из них.

для ChatGPT

2–3 кадра

Для единичных кадров или быстрого теста. Потом всё равно надо тюнить в Weavy — менять элементы, добавлять ноды.

для Weavy

10+ кадров (30 сек ролик)

Нодовый подход выгоднее когда кадров много. Поменял один параметр — пересчиталась вся серия. В чате это не масштабируется.

ошибки

Частые ошибки и как исправлять

ошибкаНеправильный промт в ноде — промт без указания ролей для каждого image. Модель угадывает что откуда.
фиксКаждый нод должен быть явно подписан в промте: use image 1 as character, use image 2 as background location, use image 3 as product on table.
ошибкаКниги и посторонние предметы появляются в кадре — модель «додумывает» интерьер гостиной из своих данных.
фиксДобавить негативный промт: no books, no decorative items. Попросить ChatGPT переписать промт с явным запретом нежеланных элементов.
ошибкаКамера «съезжает» между кадрами — угол, свет и масштаб отличаются от кадра к кадру, выглядит как киноляп.
фиксПодключить предыдущий кадр как Image 4 и прописать в промте: «image 4 is used as scene reference for camera position, lighting and object scale — do not change camera angle».
ошибкаChatGPT нарисовал вместо промта — начал генерировать, не сказали ему явно «напиши промт».
фиксВсегда начинать запрос с глагола «напиши промт для Weavy» и дописать «не рисуй». Слово «промт» в задаче обязательно.

🏠 Домашнее задание к следующей сессии

  1. Придумать идею ролика — найти референсы через RilsMaker или вручную. Выбрать продукт Atomi для рекламы.
  2. Создать персонажа в Weavy — использовать шаблон, заполнить параметры, сгенерировать character sheet в Nano Banana Pro (9:16, 2K).
  3. Собрать ноды — подключить hero + location + product как Image 1 / 2 / 3 к ноде Nano Banana Pro.
  4. Написать сценарий — хотя бы текстом, без иллюстраций. Прислать до следующей сессии вместе с референсами.
  5. Попробовать Whisper Flow — надиктовать хотя бы один промт голосом.
