01

Почему первый кадр решает всё

Весь конвейер AI-видео строится на одном принципе: нейросети для генерации видео принимают на вход начальный кадр (start frame) — статичное изображение, из которого рождается движение. Раньше видео генерировали только по тексту, и каждый кадр был независим от предыдущего. Это ломало иллюзию кинематографа.

С августа прошлого года, после Veo 3.1 от Google, технология image-to-video перевернула индустрию. Теперь качество видео полностью зависит от качества исходного кадра.

Вы не можете сделать хорошее видео из плохого кадра. Но вы можете сделать плохой кадр из хорошего видео. Запомните это правило.

— Ануар Нурпеисов, занятие 25 июня 2026

Главная задача Модуля 2

Научиться делать консистентные кадры — серию изображений с одним и тем же персонажем, в одной локации, с одним световым решением. Именно из таких кадров потом монтируется видео.

ПРОБЛЕМА КОТОРУЮ РЕШАЕТ WEAVY
  • LLM-модели не имеют памяти между запросами — каждый кадр генерируется заново
  • Один изменившийся элемент ломает весь кинематографический ряд
  • Weavy держит все референсы одновременно и применяет их к каждому новому кадру
02

Что такое Weavy и система нодов

Weavy (imagine.art) — платформа где собраны лучшие нейросети по генерации изображений. В отличие от LLM (ChatGPT, Claude) где ты пишешь в чат — Weavy работает через систему нодов.

При регистрации через Google-аккаунт ты получаешь 200 бесплатных кредитов — это около 70 фотографий в качестве 2K.

Ноды — что это такое

📦

Image-нод

Узел с изображением. Загружаешь фото (лицо, объект, локацию) — оно становится элементом который нейросеть будет воспроизводить в новом кадре.

📝

Prompt-нод

Текстовый узел. Описываешь сцену — кто где стоит, какой план, ракурс, свет. Указываешь из какого имиджа брать каждый элемент.

🎛️

Model-нод (выходной)

Окно куда приходит результат. Здесь настраиваешь качество (2K/4K), соотношение сторон (9:16/16:9), и запускаешь генерацию кнопкой Run.

🔗

Связи (коннекторы)

Линии которые соединяют ноды. Зажимаешь точку на краю нода, тянешь к другому — элемент подключён. Справа на промпте появляется список подключённых имиджей.

Сравнение с LLM

❌ ChatGPT / Claude (LLM)
  • Пишешь в чат — получаешь результат
  • Нет памяти между запросами
  • Каждый кадр — новая интерпретация
  • Персонаж меняется от кадра к кадру
✓ Weavy (Нодовая система)
  • Загружаешь элементы как ноды
  • Референсы зафиксированы навсегда
  • Один и тот же персонаж в любой сцене
  • До 14 элементов одновременно
03

Как подключать элементы: имиджи и промпт

01

Создаёшь пустой нод (правая кнопка мыши)

В рабочей области нажимаешь правую кнопку → появляется меню → набираешь «Nano Banana Pro» → выбираешь модель. Появляется пустое выходное окно.

02

Загружаешь имиджи (Image Inputs)

С левой стороны нода есть точки подключения. Нажимаешь «+» → появляются слоты для Image 1, Image 2 и т.д. Либо правая кнопка → Import → выбираешь файл с компьютера. Можно перетащить файл прямо в рабочую область.

03

Подключаешь промпт-нод

Правая кнопка → Prompt → появляется текстовое поле. Зажимаешь правую точку промпт-нода → тянешь линию → прикрепляешь к левой точке выходного нода. Промпт подключён.

04

Подключаешь имиджи к ноду

Берёшь image-нод → тянешь линию с правой точки → прикрепляешь к слоту image 1 / image 2 / image 3 на левой стороне выходного нода. Порядок важен — он указывается в промпте.

05

Настраиваешь параметры (нажав на выходной нод)

Справа появляется панель настроек: Quality (2K = 1 кредит, 4K = 23 кредита), Aspect Ratio (Auto/9:16/16:9), и кнопка Run Model.

06

Запускаешь генерацию

Нажимаешь Run Model. Если понял что что-то не так — можно остановить в любой момент, даже на 50% — кредиты вернутся.

// Правило именования в промпте
Image 1 = всегда главный герой (лицо)
Image 2 = реквизит / второстепенный элемент
Image 3 = локация / опорный кадр / поза
Image 4 = дополнительный персонаж

// Как упоминать в промпте
«Hero from image 1 stands next to the car from image 2»
«Location and arrangement of objects from image 3»
ВАЖНО — СИСТЕМНЫЙ ПОДХОД

Когда подключаешь элементы — помни кто куда подключён. Запутаешься в имиджах — промпт даст неправильный результат. Сначала герой (image 1), потом реквизит (image 2), потом локация (image 3) — держи этот порядок всегда.

04

Nano Banana Pro в Weavy

В Weavy доступны разные модели. Нас интересует Nano Banana Pro — это Gemini 2.5 Flash от Google, самая продвинутая модель для фотореализма.

🏆

До 14 элементов в кадре

Nano Banana Pro держит до 14 подключённых элементов одновременно без потери консистентности. Тексты, логотипы, детали одежды — всё сохраняется.

🔬

Гиперреализм

Поры кожи, текстура ткани, отражения — уровень детализации который был невозможен даже год назад. Разница с обычной Nano Banana видна невооружённым глазом.

💡

Логика элементов

Когда добавляешь новые элементы — Pro лучше понимает как их разместить и не теряет уже установленные детали. Обычная Nano Banana здесь начинает «глючить».

💰

Стоимость

2K = 1 кредит, 4K = 23 кредита. Начинай с 2K — разрабатывай концепцию, потом апскейли лучший кадр в 4K для финального использования.

СООТНОШЕНИЯ СТОРОН
  • 9:16 — Reels, Stories, TikTok (вертикальный)
  • 16:9 — YouTube, горизонтальное видео
  • 1:1 — квадрат (посты в Instagram)
  • Auto — Weavy сам выбирает под контент

Правила расположения элементов

📍

Указывай точную позицию каждого элемента

«Слева от героя», «справа», «за ним», «перед ним» — Weavy понимает пространственные отношения. Чем точнее — тем меньше итераций.

🎬

Указывай план и ракурс

Общий план / средний план / крупный план / деталь. Ракурс: фронтальный, 3/4, сбоку. Это влияет на то какую часть тела/объекта нейросеть покажет.

💡

Указывай световой режим

«Дневной свет», «золотой час», «неоновое освещение», «студийный свет». Без указания света нейросеть выбирает сама — результат непредсказуем.

⚠️

Если не работает дважды — проблема в промпте

Если два раза подряд результат не тот — ищи противоречие в промпте. Возможно два условия конфликтуют между собой. Перепиши с нуля, короче.

ПРОБЛЕМА С CHATGPT В WEAVY

ChatGPT теперь умеет генерировать изображения прямо в чате. Если просишь написать промпт для Weavy — он может случайно нарисовать картинку вместо текста. Всегда добавляй в конце запроса: «не рисуй, только напиши промпт».

06

Несколько кадров из одной сцены

Раскадровка видео — это серия кадров из одной сцены с разными планами и ракурсами. В Weavy можно быстро создать 4–5 кадров, скопировав ноды и изменив только промпт.

Как копировать ноды

01

Выделяешь оба нода (промпт + выходной)

Зажимаешь и выделяешь оба нода одновременно — промпт-нод и model-нод. Нажимаешь Ctrl+C → Ctrl+V.

02

Переподключаешь имиджи вручную

Связи при копировании не копируются — их нужно переподключить заново. Это занимает 30 секунд — выделяешь скопированный нод и тянешь новые линии от имиджей.

03

Добавляешь Image 3 — опорный кадр

Для второго и последующих кадров подключай первый успешный результат как Image 3 — «локация и расположение предметов из image 3». Так сцена остаётся консистентной.

04

Меняешь только план/ракурс в промпте

«Medium shot» вместо «wide shot», «close-up of the hero» — всё остальное остаётся тем же. Так получаешь разные планы одной сцены.

// Кадр 1 — Общий план
Wide shot. Hero from image 1, car from image 2,
Antarctic landscape. Daylight.

// Кадр 2 — Средний план
Medium shot. Hero from image 1, car from image 2 blurred
in background. Same location from image 3.

// Кадр 3 — Крупный план
Close-up of hero from image 1.
Same spatial arrangement from image 3.
07

Негативный промпт в Weavy

Негативный промпт — это инструкция что НЕ должно появляться в кадре. Один из 9 ключевых элементов хорошего промпта. В Weavy добавляется через Claude или прямо в текст промпта.

Как добавить негативный промпт

01

Берёшь текущий промпт из выходного нода

Ctrl+A → Ctrl+C — скопировал весь промпт.

02

Идёшь в Claude или ChatGPT

Вставляешь промпт и пишешь: «Измени промпт — добавь негативный промпт: [что не должно появиться]».

03

Копируешь обновлённый промпт обратно в Weavy

Вставляешь в промпт-нод → запускаешь генерацию заново.

// Примеры негативных промптов

Negative prompt: no blur, no artifacts,
no extra limbs, no text in frame,
no distorted faces, no unrealistic proportions

// Для позиционирования объектов
Negative prompt: cars must not be angled,
cars must not face different directions
9 ЭЛЕМЕНТОВ ХОРОШЕГО ПРОМПТА
  • Объект — кто или что главное в кадре
  • Крупность — общий / средний / крупный план / деталь
  • Ракурс — фронтальный / 3/4 / сбоку / сверху
  • Фон — локация и её детали
  • Стиль — реализм / кинематографик / эдиториал
  • Свет — студийный / дневной / неон / золотой час
  • Детализация — поры, текстуры, материалы
  • Камера — 85mm f/1.4 / Sony A7 / Leica
  • Негативный промпт — что убрать из кадра
08

Character Sheet — персонаж с нуля

Character Sheet — это набор фотографий персонажа с разных сторон на зелёном фоне. Он нужен чтобы в будущих кадрах нейросеть точно знала как выглядит твой герой с любого угла.

ПОЧЕМУ НУЖЕН ОБЩИЙ ПЛАН (НЕ СРЕДНИЙ)

Если дать нейросети только фронтальный средний план — она не знает как выглядят ноги персонажа. И при каждой генерации будет придумывать низ тела по-своему. Результат: разные костюмы, разные пропорции. Решение: всегда начинай с full body (полный рост).

Способ 1: Character Sheet из реальных фото

01

Делаешь 3 фото себя с разных ракурсов

Анфас (фронтально), три четверти, профиль (сбоку). Хорошее освещение, нейтральный фон — чем чище исходник, тем лучше результат.

02

Загружаешь в ChatGPT (Character Generator GPT)

Специальный Custom GPT от Ануара. Загружаешь 3 фото с разных ракурсов + 4-е фото — персонаж в костюме которого хочешь надеть. GPT берёт лицо с твоих фото и надевает на него костюм с 4-го фото.

03

Получаешь персонажа на зелёном фоне

GPT выдаёт тебя в выбранном костюме на зелёном фоне — это и есть Character Sheet. Сохраняешь как Image 1 для всех будущих сцен.

Способ 2: Персонаж с нуля через шаблон Weavy

Ануар поделится шаблоном — готовую структуру нодов можно скопировать и использовать. Принцип:

01

Заполняешь микропромпты по характеристикам

Пол (Female/Male), возраст, расовая принадлежность (Asian / European и т.д.), тип тела (Athletic / Slim), стиль одежды, причёска. Каждое поле — отдельный нод.

02

Prompt Container собирает всё воедино

Специальный нод объединяет все микропромпты в один. Мета-промпт сверху добавляет стиль реализма — трогать не нужно.

03

Генерируешь в полный рост (Full Body)

Step 2 в шаблоне: нажимаешь Run — получаешь персонажа в полный рост. Это матрица из которой потом делаешь все ракурсы.

04

Роутер раздаёт на 5 ракурсов

Step 3: подключаешь утверждённую фото к роутеру — он автоматически создаёт 5 вариантов: macro shot / close-up / medium shot / full body / wide shot. Один кадр → пять ракурсов.

05

Сохраняешь и загружаешь обратно в Character Generator

Берёшь лучшие 3 ракурса (анфас, 3/4, профиль) → загружаешь в ChatGPT Character Generator → получаешь зелёный фон с выбранным костюмом → это финальный Character Sheet.

ГЛАВНОЕ ПРАВИЛО CHARACTER SHEET
  • Image 1 = всегда лицо / главный ракурс персонажа
  • Трёхточечный Character Sheet = три ракурса одного человека
  • Нейросеть не знает как выглядит бок если видела только фронт
  • Чем больше ракурсов — тем консистентнее результат в сценах
09

Инструменты: Weavy Prompts GPT и Whisper Flow

Weavy Prompts GPT (Custom GPT Ануара)

Специально обученный ChatGPT который пишет промпты для Weavy. Главная особенность — понимает синтаксис «from image 1/2/3» и правильно описывает пространственные отношения элементов.

→

Как использовать

Описываешь сцену голосом или текстом: «Напиши промпт для Weavy: герой из Image 1 стоит рядом с автомобилем из Image 2 на фоне антарктиды, общий план, дневной свет». GPT выдаёт готовый промпт на английском с правильной структурой.

// Формат запроса к Weavy Prompts GPT

«Напиши промпт для Weavy.
Герой из Image 1 стоит рядом с автомобилем из Image 2.
Локация из Image 3.
Средний план, дневной свет, реализм»

// + нажимаешь / и выбираешь skill «Weavy Prompts»
// Claude понимает контекст без лишних объяснений

Whisper Flow — голосовой ввод

Приложение которое позволяет диктовать промпты голосом в любое поле на Mac. Нажимаешь кнопку → говоришь → текст появляется. Ануар активно использует его чтобы не печатать длинные промпты.

СВЯЗКА CLAUDE + WEAVY PROMPTS

Ануар показал рабочий воркфлоу: описываешь изменение в Weavy Prompts GPT → нажимаешь слэш «/» → выбираешь skill «Weavy Nano Banana» → Claude понимает контекст из проекта и пишет точный промпт. В клоде нет проблемы с «не рисуй» как в ChatGPT — он пишет только текст, чётко и без лирики.

10

NotebookLM — коробочная нейросеть для обучения

NotebookLM — продукт от Google. Бесплатен при наличии Google-аккаунта. Это коробочная нейросеть: ты загружаешь свои источники, и модель работает только с ними — без выхода в интернет, без галлюцинаций, только твои данные.

Ноутбук ЛМ не ходит на Википедию. Про Окленд он скажет только то что написано в том ролике который ты загрузил. Это делает его единственным инструментом где ты уверен в источнике каждого ответа.

— Ануар Нурпеисов, занятие 25 июня 2026

Чем отличается от ChatGPT и Gemini

❌ ChatGPT / Gemini
  • Ищет информацию по всему интернету
  • Может галлюцинировать источники
  • Не знает твоих конкретных материалов
  • Контекст теряется между сессиями
✓ NotebookLM
  • Работает только с загруженными тобой источниками
  • Всегда указывает откуда взял информацию
  • Знает твои книги, записи, транскрипты
  • Хранит библиотеку навсегда
11

Как добавлять источники

Заходишь на notebooklm.google.com → нажимаешь «+» (новый блокнот) → открывается окно загрузки источников.

4 способа добавить источники

📄

Файлы

PDF, изображения, Word-документы, аудиофайлы. Загружаешь напрямую — NotebookLM извлекает текст и анализирует.

🌐

Сайт или YouTube

Вставляешь ссылку на страницу или YouTube-ролик. NotebookLM транскрибирует видео, извлекает текст и добавляет как источник.

☁️

Google Drive

Подключаешь напрямую из своего Drive — Docs, Sheets, Slides. Не нужно скачивать и загружать заново.

📋

Скопированный текст

Берёшь любой текст (статья, Википедия, выжимка) → Ctrl+C → вставляешь в поле. Мгновенно добавляется как источник.

Три панели интерфейса

📚

Источники (слева)

Все добавленные файлы и ссылки. Можно выбрать конкретные источники для работы — NotebookLM будет отвечать только по ним.

💬

Чат (в центре)

Задаёшь вопросы как обычному AI. Разница: ответы всегда со ссылкой на конкретное место в конкретном источнике.

🎨

Studio (справа)

Форматы вывода: подкаст, презентация, инфографика, ментальная карта, тест, таблица. Один источник → много форматов.

МОЩНАЯ ФУНКЦИЯ — ВЫБОР КОНКРЕТНОГО ИСТОЧНИКА

Если загрузил 10 источников — можно выбрать работу только с одним конкретным. Пример: «Задать вопрос только по этому YouTube-ролику». NotebookLM не будет смешивать информацию из других источников.

12

Studio — форматы вывода

Studio — правая панель NotebookLM. Позволяет вывести загруженный материал в разных форматах. Не просто пересказ — полноценные артефакты.

🎙️

Подкаст (Audio Overview)

Два голоса обсуждают твой материал в формате разговора. Можно выбрать стиль: подробный анализ, краткий пересказ, дискуссия, рецензия. Ануар даже сделал подкаст в стиле прожарки на основе своей биографии.

📊

Инфографика

Структурированный визуальный вывод. За 10 минут делает приятную инфографику из текстового материала. Ануар показал пример: «10 вещей которые нужно привезти из Шри-Ланки».

🧠

Ментальная карта

Визуальная структура материала с ветками и связями. Хорошо для сложных тем где нужно увидеть целое.

📝

Тест

NotebookLM составляет вопросы по материалу и проверяет твои знания. Идеально для подготовки к экзаменам или проверки после прочтения книги.

🎞️

Презентация / Видеопересказ

Собирает структуру презентации из материала. Стиль можно задать в запросе. Ануар отмечает что Claude делает презентации лучше — но для быстрого прототипа NotebookLM работает.
