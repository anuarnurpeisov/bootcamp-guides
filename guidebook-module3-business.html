01

Почему обычный чат с Claude не работает

Когда открываешь новый чат и пишешь "напиши мне текст для клиента" — Claude не знает кто ты, что продаёшь, кто твои клиенты и какой у тебя тон. Каждый раз объяснять заново — потеря времени и получение обобщённых ответов.

Разница между ChatGPT без настройки и Claude с Projects — это разница между незнакомцем и сотрудником который с тобой уже полгода. Один знает контекст, второй приходится объяснять с нуля каждый раз.

ПРОБЛЕМА КОТОРУЮ РЕШАЕМ СЕГОДНЯ
  • Claude не помнит предыдущие чаты — каждый диалог начинается с нуля
  • Без контекста ответы общие, не под твою нишу
  • Повторяешь одно и то же описание бизнеса в каждом запросе
  • Нет единого стиля и тона — каждый ответ звучит по-разному
02

Projects — постоянная память бизнеса

Project в Claude — это рабочее пространство с постоянной памятью. Один раз загружаешь контекст бизнеса → все чаты внутри проекта автоматически знают кто ты и что тебе нужно.

📁

Project Knowledge

Файлы и тексты которые Claude читает перед каждым чатом. Загружаешь один раз — работает всегда.

💬

Чаты внутри проекта

Все диалоги создаются внутри проекта. Каждый новый чат автоматически знает твой контекст.

🎯

Custom Instructions

Правила поведения Claude именно в этом проекте: тон, роль, формат ответов.

⚡

Skills внутри проекта

Специализированные навыки вызываемые через / — прямо в чате проекта.

Как создать Project

01

Claude → Projects → + New Project

В левом меню Claude нажимаешь Projects → создаёшь новый. Называешь под бизнес, например "Мой бизнес-ассистент".

02

Project Knowledge → Add content

Внутри проекта находишь раздел Project Knowledge → добавляешь файл или текст с досье бизнеса.

03

Настраиваешь Custom Instructions

Там же добавляешь правила: как Claude должен отвечать, какой тон использовать, что всегда учитывать.

04

Создаёшь чат внутри проекта

Нажимаешь + New Chat внутри проекта (не в общем меню). Этот чат уже знает твой контекст.

03

Как составить досье для Project

Досье — текстовый файл который ты загружаешь в Project Knowledge. Чем точнее написано — тем точнее ответы Claude.

// Шаблон досье для Project Knowledge

КТО Я:
[Имя, профессия, город]

МОЙ ПРОДУКТ / УСЛУГА:
[Что именно продаёшь, как это работает, цена]

МОЯ АУДИТОРИЯ:
[Кто клиенты, их боли, почему покупают]

МОЙ СТИЛЬ ОБЩЕНИЯ:
[Тон, подача, что нельзя использовать]

МОИ ЦЕЛИ:
[Что хочу от AI, какие задачи решаю чаще всего]

ВАЖНЫЙ КОНТЕКСТ:
[Специфика ниши, термины, конкуренты, ключевые факты]
ВАЖНО — ЧЕМ КОНКРЕТНЕЕ, ТЕМ ЛУЧШЕ
  • Не "продаю курсы" → "продаю 2-недельный AI-буктемп за 69 900 тенге"
  • Не "пишу по-дружески" → "короткие фразы, без канцелярита, иногда матный юмор"
  • Не "аудитория предприниматели" → "малый бизнес Казахстана, 25-45 лет, Инстаграм"
04

Skills — обученные навыки через /команду

Skill — это сохранённая детальная инструкция для конкретной задачи. Вызывается символом / в чате. Claude применяет точную методику без отклонений — каждый раз одинаково качественно.

📌

Что такое Skill на практике

Не просто промпт — целая система инструкций с примерами, структурой, запрещёнными приёмами. Один раз написал правильно — пользуешься постоянно. Пример: Skill "Weavy Nano Banana" который использовали на Creator-треке пишет промпты в точном формате платформы.

💼

Skills для бизнеса

Скрипт ответа клиенту с зафиксированной структурой. Шаблон КП. Формат еженедельного отчёта по продажам. Тон бренда который сохраняется в каждом ответе.

⚡

Как создать Skill

Внутри Project → раздел Skills → New Skill. Пишешь название (то что будет командой), затем детальную инструкцию: что делать, как делать, примеры входа и выхода. Сохраняешь — Skill готов, вызывается через /название.

ПРИМЕР ГОТОВОГО SKILL ДЛЯ БИЗНЕСА
  • /ответ-клиенту — отвечает на входящий запрос по шаблону: приветствие → понимание боли → решение → следующий шаг
  • /кп — генерирует коммерческое предложение с нужной структурой под заданную нишу
  • /отчёт — форматирует данные о продажах в еженедельный дайджест
05

Goals и Custom Instructions

Custom Instructions — правила по умолчанию для каждого ответа в проекте. Настраиваешь один раз, работают всегда без явных указаний в каждом сообщении.

// Пример Custom Instructions для бизнес-ассистента

Роль: ты мой ассистент по продажам и маркетингу
Тон: дружелюбный, прямой, без канцелярита
Формат: краткий ответ + конкретный следующий шаг
Никогда: не используй слово "синергия" и "экосистема"
Всегда: адаптируй под казахстанский контекст
Цель: помогать закрывать сделки быстрее
🌍

Глобальные Instructions

Settings → Custom Instructions — работают во всех чатах вне проектов. Базовый уровень настройки.

🎯

Instructions проекта

Внутри Project → Instructions — перекрывают глобальные. Используй для специфики конкретного проекта.

06

Помощник vs AI-агент: в чём разница

Это терминологическая путаница которая встречается повсюду — важно понимать разницу чтобы правильно выбирать инструмент под задачу.

ПОМОЩНИК (Custom GPT / Claude)
  • Один шаг: вопрос — ответ
  • Ты задаёшь направление каждый раз
  • Не выполняет действий за пределами чата
  • Примеры: пишет тексты, генерит промпты, анализирует
  • Настраивается через Skills и Instructions
AI-АГЕНТ (Make.com + AI)
  • Многошаговая автономная система
  • Сам решает что делать дальше
  • Использует инструменты, API, внешние сервисы
  • Пример: анализирует заявку → классифицирует → отвечает → пишет в CRM
  • Настраивается через Make.com, Zapier, n8n
КЛЮЧЕВОЕ ПРАВИЛО ТЕРМИНОЛОГИИ
  • Custom GPT / Claude Skills = специализированный помощник, НЕ агент
  • AI-агент = автономная многошаговая система которая действует сама
  • Агенты живут в Make.com, Claude Projects — это помощник с памятью

Домашнее задание

Три задачи — каждая занимает не больше 15 минут. Сделай сегодня пока всё свежо в голове.

Создай Project с досье своего бизнеса

Заполни шаблон досье (Кто я / Продукт / Аудитория / Стиль / Цели) → создай Project → загрузи в Project Knowledge → скриншот в чат группы.

Создай один Skill под рутинную задачу

Возьми любое повторяющееся действие (ответ клиенту, написание поста, формат отчёта) → напиши Skill → протестируй через /команду → скриншот результата.

Протестируй разницу с Instructions и без

Задай один и тот же вопрос в обычном чате и в чате проекта с заполненными Instructions. Зафиксируй разницу — что изменилось в ответах.
