01 · Основы

Что такое LLM и почему это точка входа в ИИ

LLM (Large Language Model) — большие языковые модели. Их особенность: они обучены на огромных текстовых массивах и общаются на человеческом языке.

Почему они — вход в мир ИИ: все остальные нейросети (генерация видео, кода, сайтов) управляются именно через текстовую команду. LLM стоит на входе любой ИИ-цепочки.

LLM — это полиглот, который знает множество языков и понятий. Его главный инструмент — язык. Мы понимаем друг друга словами — и машина тоже обучена именно на них.

⚡
ChatGPT
Исполнитель
Быстро делает конкретные задачи. Нужен чёткий промпт — иначе галлюцинирует. Лучший для рутины, настроенных GPT-ботов.
🧠
Claude
Соавтор
Глубокая работа с документами, структурирование, финансовые модели, стратегия. Здесь живёт «производственный конвейер» бизнеса.
🌐
Gemini
Оркестратор
Привязан к экосистеме Google. Подключает Calendar, Drive, Gmail. Хорош для верификации информации и широкого поиска.

ChatGPT — быстрый помощник, который нахватался знаний, но его нужно проверять. Claude — думающий соавтор, с которым разрабатываете продукт изнутри. Gemini — менеджер завода: знает, куда что отправить, и умеет возвращать в реальность.

02 · ChatGPT

ChatGPT: как настроить и не тратить время впустую

A
Слабые места ChatGPT
Знания обновляются поквартально — данные устаревают. Архитектура настроена угождать: если знаний не хватает — галлюцинирует, выдаёт убедительную ложь. Использовать только там, где вы его хорошо настроили и дали правильный контекст.
B
Deep Research — поиск рутин для автоматизации
Режим глубокого исследования: модель берёт до 20 источников и выдаёт аналитику. Используйте для поиска рутинных задач в вашей нише, которые уже автоматизируют другие.
Промпт для старта
Сделай глубокое исследование на поиск рутинных задач в нише [ваша ниша], которые можно автоматизировать с помощью ИИ. Задай мне три уточняющих вопроса, чтобы подобрать наиболее популярный ответ из уже реализованных практик.
Важно: ChatGPT уточнит детали перед исследованием — ответьте точнее, результат будет лучше.
C
GPTs — предустановленные ассистенты
GPT — это чат с готовыми инструкциями под конкретную задачу. Один раз написали правила — больше не объясняете заново. Доступно на платной подписке (~$20/мес, ~10 000 тенге).

Представьте: вы говорите сотруднику — «ты проверяешь только почтовый ящик. Если пришло от налоговой — несёшь мне. Остальное не трогаешь». Один раз объяснили — он работает постоянно. GPT работает так же.

Как создать GPT за 5 минут:

1
Откройте ChatGPT → раздел GPTs → «Создать»Выбираем вкладку «Конфигурация»
2
Придумайте задачу — одну рутину, которую повторяете регулярноНапример: «генерирую темы рефератов», «рассчитываю стоимость лизинга», «пишу посты в Telegram»
3
Попросите ChatGPT написать инструкцию для этого GPTПромпт: «Напиши инструкцию для GPT, который [задача] для [ваша деятельность]»
4
Вставьте инструкцию в поле «Инструкции», нажмите «Создать»Опционально: загрузите файлы в «Знания» — методологии, списки, базы
5
Протестируйте и найдите слабые местаСкажите GPT: «Найди слабые места этой инструкции» — он сам укажет на ошибки

Инструкция — это библиотекарь, который знает, где лежит нужная книга. Знания — это сами книги. Вместе они дают точные ответы без повторных объяснений.

D
Custom Instructions — досье о вашем бизнесе
Профиль → Персонализация → Пользовательские инструкции. Загружаете сюда: кто вы, ваш продукт, ваша аудитория, их боли, ваш стиль общения, ваши цели от ИИ, где ведёте бизнес. ChatGPT запомнит это и будет учитывать в каждом ответе.
1
Откройте чат и попросите сформировать досье«Задай мне вопросы, чтобы получить весь контекст обо мне для пользовательских инструкций»
2
Ответьте на вопросы развёрнуто
3
Скопируйте результат → Персонализация → Пользовательские инструкции
Зачем: ChatGPT забывает начало разговора (контекстное окно). Custom Instructions — постоянная память. Один раз загрузили — он всегда знает, кто вы.
E
Проекты — связанные чаты
Чаты по одной теме группируйте в проект. Модель понимает контекст — что эти чаты связаны. В проект также загружаются источники и прописываются инструкции для всего проекта.
03 · Gemini

Gemini: Google-экосистема и проверка реальностью

Главное отличие от ChatGPT: Gemini идёт сначала на серверы Google и ищет самую индексируемую статью под ваш запрос. ChatGPT идёт в свою базу. Из этого вытекают плюсы и минусы.

✓ Плюс
Актуальные данные из интернета. Хорошо для широких запросов, общеизвестных фактов, верификации.
✗ Минус
На специфических темах даёт самый популярный результат, а не самый точный. Проваливается на узких задачах.

Gemini — как помощник на базаре, который знает, где что продаётся. Но если нужен конкретный сорт клубники — придётся идти к продавцу напрямую.

A
Как использовать в работе
Верификация: получили ответ в ChatGPT или Claude — идёте в Gemini, просите найти слабые места.

Калибровка стратегии: когда нашли что-то нестандартное в Claude — проверяете в Gemini, не противоречит ли это законам рынка.

Голосовой ввод + Calendar: «Внеси в план: завтра тренировка в 7:30, плавание» — добавляет в Google Календарь голосом.

Режим обучения: включается в настройках. Любой вопрос получает пошаговый понятный ответ, без сухих данных.
B
Gems — аналог GPTs
Те же предустановленные ассистенты, только внутри Gemini. Создаётся так же: название, инструкция, база знаний. Плюс — можно добавлять файлы прямо из Google Drive.
Рекомендация: не выбирайте один инструмент навсегда. Жонглируйте: ChatGPT для конкретных задач, Claude для глубокой работы, Gemini для проверки и Google-экосистемы.
04 · NotebookLM

NotebookLM: закрытая нейросеть на ваших документах

NotebookLM (Google) — это языковая модель, которую вы закрываете в ограниченное пространство. Вы загружаете источники и говорите: «работай только с ними».

Представьте: у вас есть нейросеть уровня ChatGPT, но она видит только те книги, которые вы ей дали. Не лезет в интернет. Не придумывает. Работает с вашей реальностью.

A
Какие источники можно загрузить
PDF / изображения / документы · Ссылки на сайты и YouTube-ролики · Файлы с Google Диска · Скопированный текст — вставили и всё.
B
Как выглядит интерфейс
Слева — список загруженных источников.
По центру — чат: пишете запросы, NotebookLM отвечает только по источникам.
Справа — мультимедийная студия: можно вывести в аудиоподкаст, инфографику, ментальную карту, таблицу, тест, видеопересказ.
C
Где применять в бизнесе
— Налоговый кодекс + статьи → задаёте вопросы по налогам без звонка бухгалтеру
— Методология вашей компании + инструкции → быстрые ответы для команды
— Финансовые отчёты → аналитика, таблицы, выводы
— Учебные материалы → автоматические тесты для проверки знаний
— Вся информация о проекте → ментальная карта структуры
D
Конфиденциальность
Данные хранятся в вашем Google-аккаунте. Google гарантирует защиту. Документы наружу не выходят — единственный риск это взлом вашего аккаунта. По степени доверия — такой же уровень, как к Google Drive.

Практическое задание для NotebookLM:

1
Создайте новый блокнот
2
Загрузите информацию о вашем бизнесе/проектеОписание, услуги, отзывы, методология — что есть
3
Сгенерируйте аудиоподкаст в стиле «прожарки»В мультимедийной студии → выберите подкаст → укажите стиль «прожарка»
4
Послушайте — поймёте, как NotebookLM работает с вашим контентом
