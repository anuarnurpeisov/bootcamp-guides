Автоматизация в Make.com:
Telegram → Airtable → OpenAI

Заключительный теоретический модуль. Собираем рабочую связку: Telegram-бот принимает сообщения, Make их разбирает, Airtable сохраняет как CRM-базу, а ChatGPT отвечает клиентам за вас.

Результат занятия

Собственный Telegram-бот, подключённый к Make, который записывает каждое входящее сообщение в базу Airtable: имя, username, chat ID и текст.

01Что такое Make и зачем он нужен

Make — не нейросеть. Это агрегатор-«курьер»: получает информацию из любого источника, упаковывает её и передаёт дальше по сценарию.

Триггер / Webhook
→

  • Нодовая система. Сценарий состоит из блоков (модулей), соединённых логикой. Между блоками ходят пакеты данных — сообщение плюс все его метаданные: кто написал, ID, время, откуда.
  • Webhook — самый частый инструмент. Уникальный URL, на который «прилетает» любое настроенное событие: заявка с сайта, сообщение в боте, обновление таблицы. Событие пришло — сценарий запустился.
  • Router — развилка для продвинутых. Определяет, куда передать данные: если человек идёт по кнопкам — дальше по сценарию, если пишет свободный вопрос — в блок OpenAI, где ChatGPT отвечает по вашей инструкции.
  • Google Sheets vs Airtable. Для одной простой таблицы хватит Google Sheets. Если таблиц несколько и они должны обмениваться данными — берём Airtable: это «Excel на стероидах» со связанными базами.

02Шаг 1 — создаём Telegram-бота

Бот — входная точка всей системы. Создаётся за две минуты через BotFather.

1
Находим BotFather

В поиске Telegram пишем BotFather — официальный бот с галочкой.

2
Команда /newbot

Жмём /, выбираем /newbot. Сначала бот просит имя (любое, например «Лизинг-бот»), затем username латиницей — он обязан заканчиваться на bot. Если имя занято, добавьте цифры перед словом bot: lizing123bot.

3
Копируем API-токен

BotFather выдаст сообщение с HTTP API token. Это «ДНК» бота — его уникальный ключ. Он понадобится везде, где вы будете подключать бота. Один клик по токену — он скопирован.

Лайфхак

Не понимаете, что бот или сервис от вас хочет? Скриншот → в Gemini. Он переведёт и объяснит следующий шаг.

03Шаг 2 — подключаем бота к Make

1
Новый сценарий

В Make создаём сценарий, первый модуль — Telegram Bot → Watch Updates (в русском интерфейсе «Смотреть обновления»).

2
Создаём webhook

Add hook → название (например, test1) → Create connection → вставляем скопированный токен от BotFather → Save.

3
Тестируем через Run Once

Жмём Run once слева внизу — модуль переходит в режим ожидания (крутится — это нормально). Пишем боту любое сообщение в Telegram. В модуле появляется цифра входящего пакета — значит, данные пришли: ID, имя, username, текст.

Частая ошибка

Ничего не приходит? Проверьте: (1) нажат ли Save в настройках модуля, (2) запущен ли Run Once до отправки сообщения, (3) тот ли бот открыт в Telegram. Run Once подтягивает и «застрявшие» старые сообщения — не пугайтесь старых дат.

04Шаг 3 — база в Airtable

Airtable станет вашей CRM: каждая колонка — это отдельное «поле» со своим типом данных, а не просто ячейка Excel.

Создаём токен доступа

1
Builder Hub → Create token

В Airtable: настройки → Builder Hub (раздел для разработчиков) → Create token. Название — любое, например имя компании.

2
Выдаём права (scopes)

Обязательно три: data.records:read, data.records:write, schema.bases:read. Затем в разделе Access выбираем доступ к воркспейсу. Копируем токен.

Создаём воркспейс и таблицу

1
Workspace → Create → Build an app on your own

Выбираем пустой лист (Start from scratch), а не готовые шаблоны.

2
Удаляем стандартные поля

Клик по колонке → Delete field. Важно удалять именно поле целиком, а не очищать данные — каждая колонка в Airtable это отдельная программа со своим типом.

3
Создаём четыре поля

Плюсик → выбираем тип для каждого:

ПолеТипЧто хранит
NameSingle line textИмя пользователя из Telegram
UsernameSingle line text@юзернейм
Chat IDSingle line textID чата — чтобы потом отправлять ответы этому человеку
MessageLong textТекст сообщения (может быть в несколько абзацев)

Набор полей — ваш выбор: сюда же можно собирать email и телефон, как в data collect из ManyChat.

05Шаг 4 — связываем Telegram и Airtable

1
Добавляем модуль Airtable → Create a Record

Плюсик после Telegram-модуля → Airtable → Create a Record («Создать запись»). Именно Create, не Get и не Search — мы заносим новые данные.

2
Подключаем аккаунт

Create connection → вставляем токен Airtable. Затем выбираем Base и Table, которые только что создали.

3
Маппим переменные

Кликаем в пустое поле каждой колонки — открывается панель переменных из Telegram. Ключевой момент всей связки: какие данные в какую колонку заходят.

  • Name ← Message → From → First Name
  • Username ← Message → From → Username
  • Chat ID ← Message → Chat → ID (не Message ID!)
  • Message ← Message → Text
4
Финальный тест

Save → Run Once → пишем боту сообщение → открываем Airtable. Новая строка с четырьмя заполненными полями появилась — автоматизация работает. Чтобы она крутилась без вас, включаем тумблер сценария (Scheduling ON).

Разбор ошибок с занятия

Перепутан модуль: Search Records ищет существующие записи, Get Record тянет одну по ID. Для записи входящих нужен только Create a Record.

Chat ID vs Message ID: Message ID — номер сообщения, Chat ID — адрес человека. Для будущих ответов нужен именно Chat ID.

Запись не появляется: обновите таблицу и проверьте в Make историю выполнения — если пакет прошёл, данные точно в базе.

06Что дальше: блок OpenAI

Следующий уровень — бот отвечает сам, даже когда вас нет: Telegram → Airtable → OpenAI → ответ в Telegram. Разбираем на дополнительном занятии.

Подготовка к вторнику

Для блока OpenAI нужен API-ключ — он покупается отдельно от подписки ChatGPT Plus: platform.openai.com → Billing, минимальное пополнение $5.

В блоке OpenAI мы пропишем инструкцию (как в Custom GPT) — скрипт вашей компании, по которому ChatGPT будет отвечать клиентам в боте.

Домашнее задание

  1. Создать своего Telegram-бота через BotFather и сохранить API-токен.
  2. Зарегистрироваться в Make и Airtable (оба работают через браузер).
  3. Собрать связку Telegram Bot → Airtable по пошаговому видео (придёт в группу) — база из четырёх полей должна наполняться из бота.
  4. Пополнить баланс OpenAI API на $5 (platform.openai.com → Billing) — понадобится во вторник.
  5. Вопросы и скриншоты — в Telegram-группу в любое время.
